# Sea, Signora — «Ask for»: совет официанта

Новая идея с нуля: одна фраза голосом официанта + оранжевый ярлык «ask for …» с названием блюда. Только английский.

**O-01v-akami** (7 с)
- На экране: If you order one thing from the raw bar tonight, make it this. / ask for Akami
- Подпись: If you order one thing from the raw bar tonight, make it the akami.
- Хештеги: #seasignora #akami #rawbar #brera

**O-02v-tagliolini** (7 с)
